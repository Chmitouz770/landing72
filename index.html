FAQ

Questions fréquentes

C'est quoi exactement une landing page ?

Une landing page est une page web autonome, conçue avec un seul objectif : convertir les visiteurs en prospects ou en clients. Contrairement à un site classique, elle n'a pas de menu ni de distractions.

Pourquoi 72 heures ?

On a optimisé notre processus pour aller vite sans sacrifier la qualité. 72h c'est le temps qu'il nous faut pour créer une page efficace, la tester et la livrer prête à l'emploi.

J'ai déjà un site, j'ai quand même besoin d'une landing page ?

Oui ! Votre site présente votre entreprise, mais une landing page est faite pour une action précise : lancer un produit, capter des emails, promouvoir une offre. C'est complémentaire.

Est-ce que je peux modifier ma page après ?

Bien sûr. On vous livre le code source et vous êtes propriétaire de votre page. Si vous avez besoin de modifications, on peut aussi s'en occuper.

Qu'est-ce qui est inclus dans l'hébergement du pack Pro ?

On héberge votre page pendant 3 ans sur nos serveurs rapides et sécurisés. Nom de domaine, certificat SSL (https), maintenance technique : tout est compris.

Comment se passe le paiement ?

50% à la commande, 50% à la livraison. On accepte les virements et les paiements par carte. Vous recevez une facture pour chaque paiement.
